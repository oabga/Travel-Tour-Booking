\chapter{Giới thiệu chung}

\section{Giới thiệu đề tài}

\noindent\textbf{Tên đề tài:} Hệ thống quản lý và đặt tour du lịch trực tuyến (Travel Tour Booking System).

Trong những năm gần đây, nhu cầu du lịch trực tuyến ngày càng phát triển mạnh,
đòi hỏi các doanh nghiệp du lịch cần có hệ thống quản lý hiện đại nhằm hỗ trợ
khách hàng tìm kiếm, đặt tour và thanh toán một cách nhanh chóng, thuận tiện.
Bên cạnh đó, việc quản lý lịch khởi hành, số lượng chỗ còn trống, thanh toán
và thống kê doanh thu bằng phương pháp thủ công thường gây mất thời gian và
dễ xảy ra sai sót.

Xuất phát từ thực tế đó, nhóm thực hiện đề tài
\textbf{“Travel Tour Booking System”} nhằm xây dựng hệ thống quản lý và đặt
tour du lịch trực tuyến. Hệ thống được phát triển theo kiến trúc 3 tầng
(3-Layer Architecture) gồm: Presentation Layer, Business Logic Layer và
Data Access Layer, sử dụng ASP.NET Core Web API kết hợp SQL Server và
Entity Framework Core.

Đồ án vận dụng các kiến thức và kỹ thuật quan trọng trong môn
Lập trình Cơ sở Dữ liệu như:
Stored Procedure, Trigger, Function, Transaction, View, LINQ, ADO.NET,
Entity Framework Core và RESTful API. Hệ thống hỗ trợ các chức năng:
quản lý tour, đặt tour, quản lý khách hàng, thanh toán, phân quyền người dùng,
đánh giá tour và báo cáo thống kê doanh thu.

\section{Mục tiêu đồ án}

\noindent Đồ án hướng đến các mục tiêu sau:

\begin{itemize}

\item Xây dựng hệ thống quản lý và đặt tour du lịch trực tuyến theo kiến trúc
3 tầng bằng ASP.NET Core Web API.

\item Thiết kế cơ sở dữ liệu SQL Server đáp ứng đầy đủ các nghiệp vụ quản lý
tour, booking, thanh toán và khách hàng.

\item Vận dụng kiến thức T-SQL nâng cao như View, Stored Procedure,
Function, Trigger và Transaction để xử lý dữ liệu.

\item Sử dụng Entity Framework Core, LINQ to Entities và Repository Pattern
để thao tác dữ liệu hiệu quả.

\item Xây dựng RESTful API kết hợp JWT Authentication và
Role-based Authorization.

\item Tích hợp ADO.NET theo mô hình Connected và Disconnected.

\item Xây dựng giao diện Angular 17 hỗ trợ tìm kiếm tour, đặt tour
và thống kê dữ liệu bằng Chart.js.

\item Áp dụng LINQ to XML để thực hiện chức năng xuất và nhập dữ liệu XML.

\end{itemize}
