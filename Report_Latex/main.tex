\begin{center}
  \large{\textbf{GIỚI THIỆU (ABSTRACT)}}
\end{center}
\addcontentsline{toc}{chapter}{ABSTRACT}

Đồ án xây dựng hệ thống đặt tour du lịch trực tuyến theo kiến trúc 3 tầng
(3-Layer Architecture) sử dụng ngôn ngữ C\# và nền tảng ASP.NET Core Web API.
Hệ thống quản lý toàn bộ quy trình từ đăng danh mục tour, lịch khởi hành,
đặt chỗ cho đến thanh toán và đánh giá, đảm bảo tính toàn vẹn dữ liệu thông
qua Transaction, Trigger và Stored Procedure trên SQL Server.

Phần cơ sở dữ liệu được thiết kế với 13 bảng trên SQL Server, bao gồm đầy đủ
View, Function, Stored Procedure và Trigger theo yêu cầu môn học. Phần ứng dụng
sử dụng Entity Framework Core kết hợp ADO.NET để truy xuất dữ liệu, LINQ để
xử lý nghiệp vụ, và ASP.NET Core Web API để cung cấp các RESTful endpoint.

\vspace{0.5cm}
\noindent{\textbf{Từ khóa:}} ASP.NET Core, Entity Framework Core, SQL Server,
T-SQL, LINQ, RESTful API, 3-Layer Architecture, Tour Booking.
