\chapter{Kết luận và Hướng phát triển}

\section{Kết quả đạt được}\label{Sec5.1}

Sau quá trình nghiên cứu, thiết kế và triển khai, nhóm đã hoàn thành hệ thống
quản lý và đặt tour du lịch trực tuyến theo đúng mục tiêu đề ra. Hệ thống được
xây dựng theo kiến trúc 3-layer gồm Presentation Layer, Business Logic Layer
và Data Access Layer, sử dụng ASP.NET Core Web API kết hợp SQL Server,
Entity Framework Core và Angular 17.

Đồ án đã vận dụng được nhiều kiến thức quan trọng của môn học như:
Transaction, Trigger, Stored Procedure, Function, View, LINQ, ADO.NET,

\section{Đánh giá chuẩn đầu ra}\label{Sec5.output}

Thông qua quá trình thực hiện đồ án, nhóm đã vận dụng và củng cố được
nhiều kiến thức quan trọng trong môn Lập trình Cơ sở Dữ liệu cũng như
kỹ năng làm việc nhóm.

Các kỹ năng và chuẩn đầu ra đạt được gồm:

\begin{itemize}

  \item Hiểu và áp dụng kiến trúc 3-layer trong phát triển ứng dụng Web API.

  \item Thiết kế cơ sở dữ liệu quan hệ bằng SQL Server với đầy đủ Constraint,
  View, Function, Stored Procedure, Trigger và Transaction.

  \item Hiểu Entity Framework Core, LINQ, Repository Pattern và ADO.NET
  trong truy xuất dữ liệu.

  \item Xây dựng RESTful API kết hợp JWT Authentication và
  Role-based Authorization.

  \item Phát triển giao diện Angular 17 và kết nối với backend thông qua HTTP API.

  \item Nâng cao kỹ năng làm việc nhóm, quản lý source code bằng Git/GitHub
  và xử lý conflict khi merge source.

  \item Rèn luyện khả năng tự học công nghệ mới, tìm kiếm tài liệu kỹ thuật
  và giải quyết các lỗi phát sinh trong quá trình phát triển hệ thống.

\end{itemize}

\section{Khó khăn trong quá trình thực hiện}\label{Sec5.3}

Trong quá trình thực hiện đồ án, nhóm gặp một số khó khăn như:

\begin{itemize}

  \item Việc thiết kế cơ sở dữ liệu và chuẩn hóa quan hệ giữa các bảng
  ban đầu còn nhiều sai sót và phải điều chỉnh nhiều lần.

  \item Xử lý Transaction, Trigger và Stored Procedure trong SQL Server
  yêu cầu đảm bảo tính toàn vẹn dữ liệu nên khá phức tạp.

  \item Việc tích hợp JWT Authentication và phân quyền
  Role-based Authorization gặp nhiều lỗi liên quan đến token và middleware.

  \item Trong quá trình làm việc nhóm, việc merge source code trên GitHub
  đôi lúc phát sinh conflict và mất thời gian xử lý.

  \item Kết nối và đồng bộ dữ liệu giữa Angular frontend và
  ASP.NET Core Web API cần kiểm tra kỹ định dạng dữ liệu và cấu hình CORS.

\end{itemize}

\section{Hướng phát triển}\label{Sec5.4}

Trong tương lai, hệ thống có thể được mở rộng và cải tiến theo các hướng sau:

\begin{enumerate}

  \item \textbf{Tích hợp cổng thanh toán thực tế:}
  Kết nối trực tiếp với VNPay, MoMo hoặc PayPal để hỗ trợ thanh toán trực tuyến thực tế.

  \item \textbf{Triển khai hệ thống lên Cloud:}
  Đưa hệ thống lên Azure hoặc AWS nhằm hỗ trợ nhiều người dùng truy cập đồng thời.

  \item \textbf{Phát triển ứng dụng di động:}
  Xây dựng mobile app bằng Flutter hoặc React Native để hỗ trợ đặt tour trên điện thoại.

  \item \textbf{Bổ sung AI gợi ý tour:}
  Áp dụng Machine Learning để đề xuất tour phù hợp dựa trên lịch sử đặt tour của khách hàng.

  \item \textbf{Tối ưu hiệu năng hệ thống:}
  Áp dụng Redis Cache, Pagination nâng cao và tối ưu truy vấn SQL để cải thiện tốc độ xử lý.

\end{enumerate}

\section{Bài học kinh nghiệm}\label{Sec5.5}

Thông qua quá trình thực hiện đồ án, các thành viên trong nhóm không chỉ
vận dụng được kiến thức đã học trên lớp mà còn tích lũy thêm nhiều kinh nghiệm
thực tế trong việc phát triển một hệ thống phần mềm hoàn chỉnh theo mô hình
làm việc nhóm. Mỗi thành viên đảm nhận một nhóm chức năng khác nhau và rút ra
được nhiều bài học quan trọng trong quá trình nghiên cứu, triển khai và kiểm thử hệ thống.

\vspace{0.5cm}

\noindent\textbf{- Quản lý Tour và Database:}

Trong quá trình thiết kế cơ sở dữ liệu, thành viên nhómđã học được cách
phân tích yêu cầu nghiệp vụ để xây dựng mô hình dữ liệu phù hợp và chuẩn hóa
các bảng nhằm tránh dư thừa dữ liệu. Ngoài ra, việc xây dựng Stored Procedure,
View, Function và Trigger giúp hiểu rõ hơn cách xử lý logic trực tiếp trên
SQL Server cũng như đảm bảo tính toàn vẹn dữ liệu. Thành viên cũng nâng cao
kỹ năng sử dụng Entity Framework Core, Repository Pattern và tối ưu truy vấn dữ liệu.

\vspace{0.5cm}

\noindent\textbf{- Booking và Transaction:}

Thông qua chức năng đặt tour và hủy booking, thành viên nhóm hiểu rõ hơn
về cơ chế Transaction trong SQL Server và tầm quan trọng của việc đảm bảo tính
ACID trong hệ thống cơ sở dữ liệu. Việc xử lý TRY-CATCH, kiểm tra số lượng chỗ,
Trigger cập nhật slot và kiểm soát trạng thái booking giúp nâng cao khả năng
xử lý nghiệp vụ phức tạp và hạn chế lỗi phát sinh trong quá trình thao tác dữ liệu.

\vspace{0.5cm}

\noindent\textbf{- Authentication và Authorization:}

Quá trình triển khai JWT Authentication và Role-based Authorization giúp thành viên
hiểu rõ hơn về cơ chế bảo mật trong ASP.NET Core Web API. Ngoài ra, việc phân quyền
người dùng theo vai trò Admin, Staff và Customer giúp nâng cao kỹ năng thiết kế hệ thống
bảo mật và kiểm soát quyền truy cập API. Thành viên cũng học được cách mã hóa mật khẩu
bằng BCrypt và xử lý middleware xác thực trong hệ thống.

\vspace{0.5cm}

\noindent\textbf{- Payment và Employees:}

Thông qua việc xây dựng chức năng thanh toán và quản lý nhân viên, thành viên nhóm
đã hiểu rõ hơn cách xử lý nghiệp vụ thực tế như sinh mã hóa đơn, lưu lịch sử thanh toán,
thiết kế API CRUD và quản lý dữ liệu liên quan đến nhân sự. Ngoài ra, thành viên còn cải thiện
kỹ năng thiết kế DTO, kiểm tra dữ liệu đầu vào và xây dựng API theo chuẩn RESTful.

\vspace{0.5cm}

\noindent\textbf{- Reports và Dashboard:}

Trong quá trình xây dựng chức năng thống kê và dashboard, thành viên nhóm đã nâng cao
kỹ năng xử lý dữ liệu bằng LINQ và xây dựng báo cáo doanh thu, tour phổ biến và tỷ lệ lấp đầy.
Việc sử dụng Angular 17 kết hợp Chart.js giúp hiểu rõ hơn về cách trực quan hóa dữ liệu trên giao diện web.
Ngoài ra, thành viên cũng học được cách trình bày tài liệu báo cáo bằng LaTeX và tổ chức nội dung báo cáo khoa học.

\vspace{0.5cm}

Bên cạnh các kiến thức kỹ thuật, cả nhóm còn học được nhiều kỹ năng mềm quan trọng như
làm việc nhóm, phân chia công việc, quản lý tiến độ và phối hợp giữa frontend và backend.
Quá trình sử dụng Git/GitHub giúp các thành viên hiểu rõ hơn về quản lý source code,
merge branch và xử lý conflict khi làm việc nhóm.

Ngoài ra, đồ án còn giúp các thành viên nâng cao khả năng tự học và tìm hiểu công nghệ mới,
đọc tài liệu kỹ thuật tiếng Anh và chủ động giải quyết các lỗi phát sinh trong quá trình phát triển hệ thống.
